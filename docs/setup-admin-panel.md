# راه‌اندازی پنل مدیریت (فقط یک‌بار، حدود ۲۰ دقیقه)

پنل مدیریت برای اینکه امن باشد، به یک «واسط» رایگان در Cloudflare نیاز دارد. این واسط رمز عبور شما و کلید دسترسی به GitHub را نگه می‌دارد، تا هیچ‌کدام داخل کد عمومی برنامه نباشند.

## گام ۱: ساخت حساب Cloudflare
1. به dash.cloudflare.com بروید و با ایمیل خود ثبت‌نام کنید (رایگان است، کارت بانکی نمی‌خواهد).
2. ایمیل را تأیید کنید و وارد داشبورد شوید.

## گام ۲: ساخت Worker
1. از منوی سمت چپ **Workers & Pages** را بزنید.
2. روی **Create application** (یا Create) و بعد **Create Worker** بزنید.
3. نام را `taraz-admin` بگذارید و **Deploy** را بزنید.
4. روی **Edit code** بزنید. تمام کد داخل ویرایشگر را پاک کنید (Ctrl+A و Delete).
5. فایل `worker/worker.js` را در GitHub باز کنید، دکمه Copy (کپی کل فایل) را بزنید و داخل ویرایشگر Cloudflare Paste کنید.
6. بالا سمت راست **Deploy** را بزنید.

## گام ۳: ساخت کلید دسترسی GitHub
1. در GitHub بالا سمت راست روی عکس پروفایل ← **Settings** بزنید.
2. پایین منوی چپ **Developer settings** ← **Personal access tokens** ← **Fine-grained tokens**.
3. **Generate new token** را بزنید.
   - **Token name:** `taraz-admin`
   - **Expiration:** ۱ سال (۳۶۵ روز)
   - **Repository access:** گزینه **Only select repositories** و فقط مخزن `TM_TEST_Fall_1405` را انتخاب کنید.
   - **Permissions ← Repository permissions ← Contents:** روی **Read and write** بگذارید. به هیچ مورد دیگری دسترسی ندهید.
4. **Generate token** را بزنید و متن توکن (شروع‌شده با `github_pat_`) را همان‌جا کپی کنید. بعد از بستن صفحه دیگر دیده نمی‌شود.

## گام ۴: وارد کردن تنظیمات در Worker
در Cloudflare: Worker خود را باز کنید ← **Settings** ← **Variables and Secrets** ← **Add**. شش مورد زیر را اضافه کنید. برای سه مورد اول نوع را **Secret** بگذارید:

| نام | نوع | مقدار |
|---|---|---|
| `ADMIN_PASSWORD` | Secret | رمز عبور پنل. حداقل ۱۰ نویسه؛ یک جمله طولانی بهتر است، مثلاً `کتاب-سبز-دریا-۱۴۰۵-پنجره` |
| `GITHUB_TOKEN` | Secret | توکنی که در گام ۳ کپی کردید |
| `SESSION_SECRET` | Secret | یک رشته تصادفی حداقل ۳۲ نویسه (انگلیسی و عدد، مثلاً با زدن تصادفی کلیدها). جایی لازم نیست حفظش کنید |
| `ALLOWED_ORIGIN` | Text | `https://thenimaabides.github.io` (کوچک، بدون `/` آخر) |
| `REPO` | Text | `TheNimaAbides/TM_TEST_Fall_1405` |
| `BRANCH` | Text | `main` |

بعد از افزودن، **Deploy** را بزنید.

## گام ۵: دادن آدرس Worker به برنامه
1. در صفحه Worker بالای صفحه یک آدرس مثل `https://taraz-admin.نام-شما.workers.dev` می‌بینید. آن را کپی کنید.
2. این آدرس را در گفتگوی Claude بفرستید تا در برنامه ثبت شود.
   - یا خودتان در GitHub فایل `src/config.ts` را باز کنید و بین دو علامت `''` جلوی `ADMIN_API` بنویسید، بدون `/` آخر.

## گام ۶: آزمایش
1. بعد از ۲ دقیقه (پایان Actions) برنامه را باز کنید.
2. **تنظیمات ← پنل مدیریت** را بزنید و با رمز وارد شوید.

## نکته‌های امنیتی
- رمز و توکن را فقط در Cloudflare بنویسید. هرگز در گفتگو، ایمیل یا GitHub ننویسید.
- بعد از ۵ بار رمز اشتباه، ورود از همان شبکه ۱۵ دقیقه قفل می‌شود.
- هر وقت خواستید رمز را عوض کنید، مقدار `ADMIN_PASSWORD` را در Cloudflare عوض و Deploy کنید.
- توکن GitHub بعد از یک سال منقضی می‌شود. اگر پنل پیام خطای «انتشار انجام نشد» داد، یک توکن جدید بسازید و در `GITHUB_TOKEN` جایگزین کنید.
