# راهنمای استفاده از پنل مدیریت

این راهنما برای کسی است که با برنامه‌نویسی آشنا نیست.

## ورود
1. برنامه را باز کنید: **تنظیمات ← پنل مدیریت**.
2. رمز عبور را بنویسید و **ورود** را بزنید. (نشست ورود ۱۲ ساعت معتبر است.)

## تغییر لینک ویدیو
1. **دسته‌ها ← نام دسته (مثلاً نرم‌افزار سپیدار)** را بزنید.
2. روی **فصل‌ها و درس‌ها** بزنید و درس را انتخاب کنید.
3. در بخش «ویدئو (آپارات)» لینک جدید را بچسبانید. هر دو شکل قبول است:
   - لینک ویدیو: `https://www.aparat.com/v/xxxxx`
   - یا کد جاسازی (iframe) که آپارات در «اشتراک‌گذاری ← کد جاسازی» می‌دهد.
4. اگر درست باشد، پیش‌نمایش ویدیو زیر کادر دیده می‌شود. اگر لینک ناشناخته باشد، پیام هشدار می‌آید.
5. پایین صفحه **انتشار** را بزنید.

## افزودن یا ویرایش متن درس
1. داخل درس، **+ متن** را بزنید و متن را بنویسید. برای رفتن به خط بعد، Enter بزنید؛ همان‌طور که نوشتید نمایش داده می‌شود.
2. هر بخش را با دکمه‌های ▲ و ▼ بالا و پایین ببرید. متن‌ها و ویدیوها به ترتیبی که می‌چینید زیر هم نمایش داده می‌شوند.
3. برای حذف یک بخش، آیکن 🗑 را بزنید.
4. در پایان **انتشار** را بزنید.

## افزودن یا تغییر نام دوره، فصل، درس
- داخل هر دسته: **+ افزودن دوره**. نام دوره را مستقیم داخل کادر عوض کنید.
- داخل دوره: **+ افزودن فصل** و زیر هر فصل **+ افزودن درس**.
- ترتیب و حذف با ▲ ▼ 🗑.
- بعد از هر تغییر **انتشار** را بزنید.

## انتشار و نمایش برای دانشجو
- تا «انتشار» را نزنید، تغییرات فقط روی همین دستگاه ذخیره می‌ماند (پیش‌نویس). اگر صفحه بسته شود و دوباره بیایید، بازیابی می‌شود.
- بعد از انتشار، حدود ۱ تا ۲ دقیقه طول می‌کشد تا برای دانشجوها نمایش داده شود. اگر برنامه باز باشد، خودش محتوای جدید را می‌گیرد.
- **دور انداختن** همه تغییرات منتشرنشده را برمی‌گرداند.

## نکته‌ها
- فقط یک نفر در یک زمان ویرایش کند. اگر پیام «محتوای منتشرشده تغییر کرده» آمد، یعنی کسی دیگر (یا دستگاه دیگر) ویرایش کرده؛ برای جلوگیری از پاک شدن کار او، انتشار انجام نمی‌شود.
- تصویر و فایل PDF هم از همین پنل قابل افزودن‌اند (+ تصویر، + PDF / فایل). حداکثر حجم هر فایل ۲۰ مگابایت.
- اگر خطا دیدید، عکس صفحه را برای مدیر فنی بفرستید.
