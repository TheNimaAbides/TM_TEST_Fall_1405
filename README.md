# ترازمشاور (آزمایشی)

نسخه اولیه PWA آموزشی (React + Vite). ساخت و انتشار روی GitHub Pages **خودکار** انجام می‌شود؛ شما نیازی به نصب Node.js یا اجرای دستور ندارید.

## راهنمای انتشار (فقط یک‌بار)

### گام ۱: ساخت مخزن در GitHub
1. به github.com بروید و وارد حساب خود شوید.
2. بالا سمت راست روی **+** و سپس **New repository** بزنید.
3. نام مخزن را مثلاً `taraz` بگذارید (فقط حروف انگلیسی).
4. گزینه **Public** را انتخاب کنید و **Create repository** را بزنید.

### گام ۲: بارگذاری فایل‌ها
1. فایل ZIP را از حالت فشرده خارج کنید.
2. در صفحه مخزن روی **uploading an existing file** بزنید.
3. **همه‌چیز داخل** پوشه `TarazMoshaver-Experimental` را انتخاب کنید (نه خود پوشه)، شامل پوشه‌های `src`، `public` و `.github`، و بکشید داخل صفحه.
4. پایین صفحه روی **Commit changes** بزنید.

> اگر پوشه `.github` را در Explorer نمی‌بینید: در ویندوز در منوی View گزینه **Hidden items** را فعال کنید.
> اگر بعد از بارگذاری پوشه `.github` در مخزن دیده نشد: در مخزن **Add file ← Create new file** را بزنید، در کادر نام این را تایپ کنید: `.github/workflows/deploy.yml` و محتوای فایل `deploy.yml` را داخلش کپی کنید.

### گام ۳: فعال‌سازی GitHub Pages
1. در مخزن به **Settings ← Pages** بروید.
2. در بخش **Source** گزینه **GitHub Actions** را انتخاب کنید.
3. به تب **Actions** بروید. یک کار به نام «Deploy to GitHub Pages» در حال اجراست؛ حدود ۲ دقیقه صبر کنید تا تیک سبز بزند.
   - اگر هنوز اجرا نشده بود: روی همان نام کلیک کنید و **Run workflow** را بزنید.
4. دوباره به **Settings ← Pages** بروید؛ لینک برنامه آنجا نوشته شده است:
   `https://نام‌کاربری.github.io/taraz/`

## آزمایش روی موبایل

**Android (Chrome):** لینک را باز کنید ← منوی ⋮ ← **Install app** (یا Add to Home screen).

**iPhone (حتماً با Safari):** لینک را باز کنید ← دکمه Share ← **Add to Home Screen**.

**آزمایش آفلاین:**
1. برنامه را یک‌بار با اینترنت کامل باز کنید و چند ثانیه صبر کنید.
2. اینترنت را قطع کنید (حالت هواپیما) و برنامه را ببندید و دوباره باز کنید.
3. باید داشبورد و صفحه‌ها بدون اینترنت باز شوند.

نکته: فونت وزیرمتن از اینترنت گرفته می‌شود؛ اگر در اولین باز شدن اینترنت وصل بوده باشد، ذخیره می‌شود. در غیر این صورت فونت جایگزین دستگاه دیده می‌شود.

## اجرا روی رایانه (اختیاری)
```powershell
npm.cmd install
npm.cmd run dev
```

## تغییرات این نسخه
- رفع خطای ساخت: فایل `src/vite-env.d.ts` اضافه شد (بدون آن `npm run build` در مرحله TypeScript خطا می‌داد).
- افزودن Workflow انتشار خودکار روی GitHub Pages (`.github/workflows/deploy.yml`).
- Service Worker: فایل‌های ساخته‌شده برنامه (js و css) هنگام نصب کش می‌شوند؛ قبلاً فقط بعد از بار دوم باز کردن آفلاین کار می‌کرد. صفحه‌ها network-first با زمان‌سنج ۵ ثانیه.
- آیکن‌ها: آیکن maskable جداگانه برای Android و آیکن ۱۸۰ پیکسلی مخصوص iPhone.
- افزودن تگ‌های لازم iOS برای اجرای تمام‌صفحه.

## هنوز پیاده‌سازی نشده
پنل مدیریت، دانلود انتخابی آفلاین، بررسی واقعی نسخه جدید، و انتشار امن از پنل به GitHub (مراحل بعدی). توکن GitHub هرگز نباید داخل کد برنامه قرار گیرد.
